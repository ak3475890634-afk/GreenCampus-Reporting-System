# Green Campus Environmental Issue Reporting System

## Project Overview
A web-based system for reporting and managing environmental issues on a college campus.

## Problem
Students and staff may notice problems such as:
- Garbage and waste
- Water leakage
- Broken lights
- Unclean areas
- Other environmental issues

## Proposed Solution
The system allows users to report environmental issues so that they can be tracked and resolved efficiently.

## Features
- Report environmental issues
- Add issue details
- Track reported issues
- Manage and resolve complaints
- Improve campus cleanliness

## Technologies
- HTML
- CSS
- JavaScript

## Future Scope
- User login
- Image upload
- Location/GPS support
- Admin dashboard
- Issue status tracking
